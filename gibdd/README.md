# Списки камер Госавтоинспекции

Стационарные комплексы фотовидеофиксации, опубликованные по 257-ФЗ (ст. 22.1) на сайте Госавтоинспекции,
раздел региона «Места установки средств фотовидеофиксации». Сайт открывается только из России, поэтому файлы
кладутся сюда вручную (ежемесячно): `complex_spb.xlsx`, `complex_lo.xlsx`, месяц — в `index.json`.

Сбор данных (`data-refresh`) сверяет их с камерами OpenStreetMap: подтверждает совпавшие, добавляет недостающие,
помечает камеры OSM, которых в списке нет.
